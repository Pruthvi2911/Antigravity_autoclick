# Install Antigravity AutoClick

This folder contains a copy of the v0.2.0 VSIX prepared for the release. It is preserved unchanged when source packages are rebuilt.

1. Open **antigravity-option2-0.2.0.vsix** above and click **Download raw file**, or [download it directly](https://github.com/Pruthvi2911/Antigravity_autoclick/raw/refs/heads/main/Antigravity-AutoClick/antigravity-option2-0.2.0.vsix).
2. In Antigravity, open **Extensions → … → Install from VSIX…**.
3. Select the file and reload if asked.
4. Click **Option 2: OFF** in the status bar to enable. Click again to stop.

Windows only. Keep Antigravity in the foreground. While enabled, matching commands are approved automatically for their conversation, without command review. Experimental preview.

Developers: source code is in [../src/](../src/) and build instructions are in the [main README](../README.md). New source builds are generated in `dist/`; promoting a new release into this folder is a separate explicit step.
